# Contributors

This project is licensed under AGPL-3.0-or-later (see [LICENSE](LICENSE)). There is no CLA and
no copyright assignment — each contributor keeps copyright over their own contribution, licensed
to the project under the same AGPL-3.0-or-later terms (see [CONTRIBUTING.md](CONTRIBUTING.md)).

Because copyright on any given piece of code stays with whoever wrote it, relicensing the project
later (in whole or in part, e.g. for a separately-licensed plugin/API layer) would require
separate consent from each contributor who holds copyright on the code involved. This file exists
so that "who holds copyright on what" has a clear, append-only record instead of needing to be
reconstructed from `git log` later.

Every PR that adds copyrightable content must add a line below as part of the same PR (see the PR
template checklist). One line per contributor is enough — don't add a new line for every PR, only
for your first contribution.
